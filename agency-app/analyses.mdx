## Overview

A **saved analysis** is an investigation the assistant ran in the chat panel,
kept with its question, the steps it took and its findings. Re-run it later to
see what changed. Choose **Saved analyses** in the navigation.

## Save an analysis

Ask a question in the chat panel. When the answer is useful, say "save this
analysis". The assistant saves:

- the question you asked,
- each step: the data it read, and the numbers it found,
- its findings.

Steps that read a date range, such as the last 7 days, are saved relative to
today, so a re-run reads a fresh window.

## The list

From the agency, use the client picker to show one client or **All clients**.
Each analysis has:

- **Re-run with fresh data**: runs every step again now.
- **Open steps**: shows the question, findings and each step.
- **Delete**: removes the analysis for everyone. It cannot be undone.

## Compare then and now

After a re-run, each step shows its numbers side by side:

| Column | Meaning |
| --- | --- |
| **Measure** | What the number is. |
| **Then** | The value when the analysis was saved. |
| **Now** | The value from the re-run. |
| **Change** | The difference, or **Same** if nothing changed. |

If a step fails on the re-run, it shows the error instead.
