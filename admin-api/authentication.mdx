## Admin session

Every Admin API endpoint requires a Supabase session JWT for an allowlisted admin account, passed as a bearer token.

<ParamField header="Authorization" param-type="string" required="true" deprecated="false">
  Supabase session JWT for an allowlisted admin account. Format: `Bearer <access_token>`.
</ParamField>

<Callout kind="alert">
  Admin session tokens must never be exposed in client-side JavaScript, public repositories, or logs. Only accounts on the admin allowlist can obtain a session that passes this check.
</Callout>
