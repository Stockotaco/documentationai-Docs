## Authentication

Every endpoint requires a Supabase session JWT for an allowlisted admin account, passed as a bearer token.

<ParamField header="Authorization" param-type="string" required="true" deprecated="false">
  Supabase session JWT for an allowlisted admin account. Format: `Bearer <access_token>`.
</ParamField>

<Callout kind="alert">
  Admin session tokens must never be exposed in client-side JavaScript, public repositories, or logs. Restrict access to trusted backend services and operations staff.
</Callout>

<Callout kind="info">
  The admin session that authenticates these requests is distinct from an agency's own `agency_key` (the `ak_` credential returned by these endpoints). The admin session authorizes management of agencies; the `agency_key` is used by client-facing APIs to identify a specific agency.
</Callout>
