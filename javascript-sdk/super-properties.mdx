## Super properties

Super properties are automatically merged into every event. Use them for values that should be attached to all subsequent events, like a user's subscription plan or A/B test variant. They are persisted in storage and survive page reloads until cleared.

<Callout kind="info">
  Super properties are attached to every event you send. To set properties **on the user's profile** instead, pass them as the second argument to [`identify()`](/javascript-sdk/tracking-methods), which sends them as a `$set` event.
</Callout>

### `set(properties)`

Set one or more super properties. Overwrites existing values.

```javascript
mythic.set({ plan: "enterprise", team_size: 50 });
```

### `set_once(properties)`

Set super properties only if they do not already exist.

```javascript
mythic.set_once({ first_seen_campaign: "spring_2024" });
```

### `unset(property)`

Remove a single super property.

```javascript
mythic.unset("temporary_flag");
```

### `get_property(property)`

Retrieve a single super property value.

```javascript
const plan = mythic.get_property("plan"); // "enterprise"
```

### `get_super_properties()`

Retrieve all super properties as an object.

```javascript
const allProps = mythic.get_super_properties();
```

### `clear_super_properties()`

Remove all super properties.

```javascript
mythic.clear_super_properties();
```

## Auto-populated super properties

The SDK manages some super properties for you when experiment detection is enabled with [`capture_experiments`](/javascript-sdk/configuration). Once Convert.com buckets the visitor, these properties are added to every event and persist for the rest of the session. See [`$experiment_viewed`](/javascript-sdk/auto-captured-events) for the event emitted when an experiment is detected.

### `$experiments`

Contains an array of experiment and variation pairs in the format `"<experimentId>:<variationId>"`.

```javascript
{
  "$experiments": ["12345:67890", "98765:43210"]
}
```

### `$ab_platform`

Contains the name of the testing tool that provided the bucket assignment. The current value is `"convert"`.

```javascript
{
  "$ab_platform": "convert"
}
```

<Callout kind="info">
  Calling `set()`, `set_once()`, or `unset()` on `$experiments` or `$ab_platform` has no effect. The experiment detection module manages these properties automatically.
</Callout>
